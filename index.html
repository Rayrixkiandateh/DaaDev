Halo! Saya adalah seorang developer dan antusias game yang berdomisili di Jabar. Saya sangat menikmati warna abu-abu karena melambangkan ketenangan dan keseimbangan — prinsip yang saya bawa saat memecahkan masalah atau menulis kode.

Keahlian saya mencakup pengembangan web (HTML, CSS, JS), Python, dan pembuatan sistem terautomasi. Saat ini, saya juga sedang aktif mengembangkan BookOfPrograms, sebuah addon Minecraft Bedrock yang dirancang secara khusus untuk mengajarkan fungsionalitas command block melalui UI yang interaktif.

Di luar layar komputer, jika saya sedang berjalan-jalan dan bertemu kucing — entah itu kucing liar atau peliharaan — saya pasti akan berhenti sejenak untuk mengelusnya. Keseimbangan antara teknologi dan dunia nyata adalah kunci kreativitas saya! 🐱
